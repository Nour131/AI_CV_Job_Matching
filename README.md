## Overview

AI_CV_Job_Matching is an AI-powered CV screening and job-matching system designed to evaluate candidate CVs against technical internship requirements.

The system processes CVs in multiple formats and combines keyword matching, semantic similarity, evidence-based scoring, and AI/technical relevance filtering to rank candidates according to their suitability for the role.

## Key Features

- Automated CV text extraction and preprocessing
- Support for PDF and DOCX CV files
- AI and technical relevance filtering
- Keyword-based skill matching
- Semantic similarity using Sentence Transformers
- Evidence-based candidate scoring
- Weighted evaluation of job requirements
- Candidate ranking and match classification
- Excel export of final matching results

## Technologies Used

- Python
- Pandas
- Sentence Transformers
- Scikit-learn
- PyMuPDF
- python-docx
- OpenPyXL
- Google Colab

## Project Workflow

1. Load and process candidate CVs.
2. Extract and clean CV text.
3. Define technical job requirements and scoring weights.
4. Evaluate candidates using keyword and semantic matching.
5. Measure evidence of relevant technical experience.
6. Apply AI/technical relevance filtering.
7. Calculate final weighted match scores.
8. Rank candidates and export the results to Excel.
